# CG-MoE priority anchor

This repository is a quiet public timestamp for the CG-MoE
project's claims. It intentionally contains only:

- `PRIORITY_NOTICE.md` — the claims, dated, in final-system
  language.
- `PAPER_ADDITIVE.tex` — the whitepaper stating the claims with
  their measured support.
- `EVIDENCE_MANIFEST.sha256` — sha256 hashes of the sealed
  evidence files (kept private until the project's publication
  schedule).

The implementation, measurement tools, and launch plan remain
private. This repository exists so that the claims and their
evidence binding have a public, dated, third-party-retrievable
record.
